> [!WARNING]

> ### Антивирусное ПО
> Антивирус может среагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик, поэтому он необходим для работы zapret.
> Один и тот же инструмент могут использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы хорошо понимаете настройки исключений, предпочтительно добавить исключение. При отсутствии такой уверенности рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`; провайдер Cloudflare может оказаться заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы. Инструкция находится [здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках опцию "Транзит запросов". Если её отключить, Secure DNS на компьютере может работать некорректно

2. Получите zip/rar-архив с [последнего релиза](https://github.com/StonemasonCrypt/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте пункт "Разблокировать". При использовании 7-Zip или PeaZip этот шаг не требуется

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить запуск вместе с системой, используйте **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую**

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб
  - **`Check Status`** показывает состояние обхода и служб: стратегии, запускаемой автоматически, и WinDivert
  - **`Game Filter`** меняет режим обхода для игр и других приложений, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** задаёт режим обхода для сервисов из `ipset-all.txt`.  
  Это полезно при проверке ресурса, который перестаёт работать при включённом zapret.  
  В скобках указывается режим:
    - `none` - проверка не применяется ни к одному IP
    - `loaded` - IP сопоставляются со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений
  - **`Replace active fakes`** меняет используемый фейк на другой файл из каталога `bin`
  - **`Update IPSet List`** заменяет `ipset-all.txt` актуальной версией из репозитория
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` - тестирует сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и проблемы

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если он не запустился, обратитесь к [#522](https://github.com/StonemasonCrypt/zapret-discord-youtube/issues/522)

### Подходящей стратегии нет
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Веб-версия Telegram не подключается
Откройте **`service.bat`** и запустите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - В появившемся каталоге откройте файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленный аналогичный блок
  - Сохраните файл и проверьте соединение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантирован. При неудаче используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/StonemasonCrypt/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который некоторое время успешно работал, может перестать помогать после того, как его обнаружат.
> В репозитории есть разные стратегии обхода. Если ни одна не подходит, создайте новую на основе одной из существующих и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте `service.bat` -> `Run Diagnostics` и устраните найденные ошибки

- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов

- Переключитесь на другие варианты, например **`ALT`** или **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/StonemasonCrypt/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце выберите Y
- Удалите прежнюю папку zapret
- Загрузите свежий архив (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/StonemasonCrypt/zapret-discord-youtube/releases)
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу есть пункт разблокировки, отметьте его, нажмите применить и подтвердите кнопкой ОК
- Распакуйте архив в новый каталог в корне диска, используя путь без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не восстановился, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочего варианта включите автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` - в **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Используйте инструкцию из https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть в службах

1. Получите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям
- Переберите остальные стратегии, особенно если раньше всё работало
- См. также [#251](https://github.com/StonemasonCrypt/zapret-discord-youtube/discussions/251)

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала определите стратегию, с которой открывается YouTube, и запустите её
- В `service.bat` выберите `Run Diagnostics` и очистите там кэш Discord
- Проверьте приложение Discord и выясните, помогла ли очистка кэша
- Откройте Discord в браузере по адресу https://discord.com/app. Если браузерная версия работает, можно пользоваться ей
- Если Discord не работает и в браузере, снова проверьте все стратегии: одна может открывать YouTube, но не Discord
- См. также [#252](https://github.com/StonemasonCrypt/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/StonemasonCrypt/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсального варианта:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Лучше определить IP-адреса, которые использует игра, и добавить их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/StonemasonCrypt/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблемы нет в списке

- Оформите её [здесь](https://github.com/StonemasonCrypt/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены будут учтены автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - исключения для IP-адресов и подсетей
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
